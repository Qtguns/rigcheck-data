# RigCheck open data

The data behind the [RigCheck](https://localrigcheck.com) checkers ("can your hardware run this AI model?"), as JSON.
This repository is a copy of <https://localrigcheck.com/data/>, updated after a site update changes the files (a
rebuild that only changes a file's `generated` date is not copied). From 21 October 2026, each copy is a commit. A
copy can lag behind the site for a few days, and if a copy fails and the data changes again before the next one, the
version in between is not kept; the live files are the reference.

## Files

| File | What it contains |
| --- | --- |
| `models.json` | Per model: the file sizes and memory figures the checkers work from, with each page's update and sources-checked dates |
| `strata.json` | Strata engine: size options, memory needs and benchmarks, each with its source and type (measured, community report or estimate) |
| `hardware.json` | The graphics cards and Macs the checkers offer: label, vendor, memory and, where a source is recorded, bandwidth |
| `catalog.json` | The model catalog: model pages, variants, input and output types and which checkers answer for each |
| `fit/<model>.json` | Each model page's "Common setups" table: the checker's quick answer on eight fixed setups, with its conditions |

File sizes, published benchmarks and publishers' memory tables come from the sources named on each page. Fit answers
are of different kinds, named in each fit file's `answerKinds`: a RigCheck capacity estimate, a planning budget, or a
match against an official route, a published route or recipe, or a project's published requirements. None is a
tested setup; see <https://localrigcheck.com/methodology/>. An answer of "unknown"
means there is no route or source to check, not "does not fit".
